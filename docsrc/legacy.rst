Legacy Frontends
================

Documentation for the FX compilation frontend. This frontend
is in maintenance mode — for new projects use the Dynamo frontend
(``torch.compile`` or ``torch.export``).

The TorchScript frontend has been removed. See :doc:`py_api/ts` for migration.
