Detailed Description
--------------------

The processed blob uses the standalone TR01 wire format from py/torch_tensorrt/executorch/serialization.py and is parsed directly here. This runtime path intentionally does not depend on the legacy Torch-TensorRT C++ runtime or libtorch.
